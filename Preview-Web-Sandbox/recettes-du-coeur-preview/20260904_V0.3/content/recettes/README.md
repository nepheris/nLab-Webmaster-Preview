# Flux éditorial recettes

Ce dossier est réservé aux apports éditoriaux complémentaires et aux futures recettes validées.

## Règle d’intégration Chef

Une recette Chef n’entre dans le site public que lorsque son statut `READY_FOR_P002` est prouvé.

Au 26 août 2026, le cockpit Chef indique `0 READY_FOR_P002`. La VNext conserve donc les 13 recettes déjà publiées et n’intègre aucune candidate non validée.

Les données structurées existantes restent servies par :
- `data/public/recettes.json`
- `data/referentiels/recettes.json`

L’éditorial de présentation du site est stocké sous `content/pages/*.md`.
