Modèle V1

Le schéma couvre : recettes, ingrédients de recette et rôles, grammages scalables, nutrition pour 100 g, nutrition par portion, statut Nutri-Score, traductions, techniques, matériel et relations.

Les extensions matériel ajoutent acquisition/cycle de vie puis identification de l’exemplaire et preuves visuelles : modèle, PNC/IAN/références, numéro de série privé, plaque signalétique, photos de commandes/accessoires, maintenance et réparations.

Point de provenance : la maquette P002 J0.5 vérifiée ne contenait pas de base SQLite locale ; elle consommait Markdown/YAML et JSON publics. La couche SQL présentée ici est donc la première implémentation SQL P019, construite à partir de ces sources vérifiées.

Confidentialité matériel

Les numéros de série, photos de plaque signalétique, justificatifs d’achat et autres identifiants propres à l’exemplaire sont privés par défaut. Une copie nettoyée peut être publiée séparément.

Règles nutrition

Les valeurs nutritionnelles affichées sont des estimations documentées. Un Nutri-Score n’est publié que lorsque les données nécessaires et la version d’algorithme sont présentes ; sinon le statut reste non_calculable ou not_calculated.
